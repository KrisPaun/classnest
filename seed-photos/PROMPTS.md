# AI photo prompts (demo only)

Use any image generator (ChatGPT/DALL·E, Midjourney, Adobe Firefly, Ideogram, Leonardo).
Make **3 images per experience** and save them as `1.jpg`, `2.jpg`, `3.jpg` in the folder shown. Then run `npm run seed:photos`.

**Rules**
- Landscape, 3:2 (for example 1536×1024). Keep each file under 5 MB (JPG or WebP is smaller than PNG).
- Photos are AI-generated: label the demo as "примерни слики" and replace them with real host photos before launch.
- Do not ask for real people, brands or logos. Hands and background figures only.
- Add this suffix to every prompt: `natural light, candid documentary style, shallow depth of field, warm tones, realistic, no text, no logos`

**The 3 shots for each experience**

1. Wide scene of the workshop with 4–6 people from behind or at a distance.
2. Close-up of hands working with the materials.
3. Finished result on a table, warmly lit.
