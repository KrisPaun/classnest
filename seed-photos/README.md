# Seed photos

Put photos here, one folder per experience (folder name = experience slug), then run:

```bash
npm run seed:photos
```

JPG, PNG or WebP, up to 5 MB each, up to 12 per experience. The first file (alphabetically) becomes the main photo.
Use only photos you own or that have a licence allowing commercial use.
